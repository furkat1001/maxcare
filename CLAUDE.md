# MaxCare

Родительский контроль для детей до 16 лет: фильтрация опасного контента, геолокация, ежедневный отчёт родителю.
Рынок — Узбекистан: интерфейс и фильтры на узбекском (латиница и кириллица), русском и английском.

Два приложения:
- **MaxCare Kids** — телефон ребёнка. Android — нативный Kotlin, iOS — Swift.
- **MaxCare** — приложение родителя на Flutter (Android и iOS).

Все решения по функциям и ограничениям платформ — в `docs/research.md`, план работ — в `docs/roadmap.md`.

## Структура репозитория

```
android/
  app-kids/       приложение ребёнка (точка сборки)
  core/           общие модели, хранилище, шифрование
  protection/     Device Admin и Device Owner (DPC), политики, защита от удаления
  accessibility/  служба доступности: текст на экране, поиск, скриншоты
  netfilter/      локальный VPN/DNS, SafeSearch, строгий режим YouTube
  ml/             on-device модели: нагота, насилие, текст (LiteRT)
  blocker/        экраны-заглушки, размытие
  location/       геолокация, геозоны
  reports/        сбор событий, очередь отправки на сервер
  setup/          экраны приложения ребёнка (Compose): мастер настройки, статус, отключение защиты; привязка к родителю
ios/              App + расширения (ContentFilter, URLFilter, DeviceActivityMonitor, ShieldConfiguration)
parent-app/       Flutter
backend/          Kotlin + Ktor, PostgreSQL, Redis
ml-research/      обучение, оценка и экспорт моделей (Python)
docs/
```

## Команды

```bash
# Android
./gradlew :app-kids:assembleDebug
./gradlew test                       # unit-тесты всех модулей
./gradlew :app-kids:connectedCheck   # инструментальные тесты (эмулятор или телефон)
./gradlew lint detekt ktlintCheck

# Device Owner на тестовом телефоне (только после сброса, без аккаунтов)
adb shell dpm set-device-owner uz.maxcare.kids/.protection.MaxCareAdminReceiver

# Backend
cd backend && ./gradlew test run

# Приложение родителя
cd parent-app && flutter analyze && flutter test

# iOS
xcodebuild test -scheme MaxCareKids -destination 'platform=iOS Simulator,name=iPhone 16'
```

Перед тем как считать задачу готовой: сборка проходит, тесты и линтеры зелёные.

## Идентификаторы

- Android: `uz.maxcare.kids` (ребёнок), `uz.maxcare.parent` (родитель).
- iOS: `uz.maxcare.kids` и расширения `uz.maxcare.kids.<extension>`, `uz.maxcare.parent`.
- Название в магазинах: «MaxCare Kids» и «MaxCare». Не использовать старое рабочее название SafeNet в коде, ресурсах и текстах.

## Версии и платформы

- Android: `minSdk 26`, `targetSdk 36` (требование Google Play с 31.08.2026).
- Фильтр изображений через `AccessibilityService.takeScreenshot` — только с API 30; на старых версиях функция отключается, остальное работает.
- iOS: Screen Time API (FamilyControls, ManagedSettings, DeviceActivity) только при авторизации `.child`. Каждое расширение — отдельный bundle ID.
- Учитывать агрессивное закрытие фоновых служб на Xiaomi/HyperOS, Tecno, Infinix.

## Приватность и безопасность — обязательные правила

Нарушение любого пункта — блокер для мерджа.

- Скриншоты и текст с экрана анализируются **только в памяти**. Не писать их на диск, в логи, в Crashlytics, в аналитику.
- На сервер уходят **только события** (что, где, когда). Содержимое — только для того, что ИИ пометил как опасное.
- Для удалённых элементов фиксировать факт удаления всегда; содержимое — только если оно раньше было помечено как опасное.
- Пароль родителя — только хеш (Argon2 или PBKDF2), с лимитом попыток. Никогда в логах и в открытом виде.
- Локальные данные шифровать: Android Keystore + Tink, на iOS — Keychain.
- Сеть — только TLS с привязкой сертификата.
- Никаких скрытых режимов: постоянное уведомление, видимая иконка и логотип MaxCare на обоях главного экрана обязательны (политика Google Play о мониторинге).
- Мессенджеры: не сохранять переписку целиком — только оповещения о сигналах опасности с коротким фрагментом.
- Тестовые данные — только синтетические. Реальные данные детей в репозиторий и тесты не попадают.
- **Никогда** не собирать, не хранить и не использовать изображения с несовершеннолетними — ни для обучения, ни для тестов.

## Запрещено трогать

- Ключи подписи (`*.jks`, `*.keystore`), `keystore.properties`, `.env`, `google-services.json`, `GoogleService-Info.plist`.
- Production-конфиги и секреты сервера.
- Ключ подписи MaxCare Kids критичен: обновить приложение в режиме Device Owner можно только той же подписью.

## Как работать

- Задачи в `protection/`, `netfilter/`, `accessibility/`, `reports/`: сначала план без правок, потом код. Любое изменение — с тестами и пометкой в PR, что нужна проверка на реальном телефоне.
- Новая политика Device Owner или новое разрешение Android — сверить с политиками Google Play (Accessibility, фоновая геолокация, доступ к фото/видео, VpnService) и указать в PR.
- Обработка текста: нормализация до сравнения со словарём — регистр, латиница/кириллица, транслит, замены букв цифрами и символами, повторы букв.
- ИИ-модели: инференс ≤ 100 мс на кадр на телефоне среднего класса, кадр раз в 1–2 с, пропуск анализа при неизменном экране. Модели обновляются с сервера без обновления приложения.
- Не добавлять зависимости без необходимости; у каждой новой библиотеки и модели проверять лицензию.

## Стиль кода

- Kotlin: Coroutines и Flow, без RxJava. DI — Hilt. Не блокировать главный поток.
- Модули общаются через интерфейсы в `core/`; `app-kids` только собирает модули.
- Строки интерфейса — только через ресурсы (`uz`, `uz-Cyrl`, `ru`, `en`), без хардкода.
- Имена в коде и коммиты — на английском; комментарии и документация — можно на русском.
