# Google Play: декларация фоновой геолокации

Пакет для публикации MaxCare Kids (`uz.maxcare.kids`): обоснование доступа к
местоположению в фоне, ответы формы Data Safety, текст заметного раскрытия и
пункт для политики конфиденциальности. Заполняется в Play Console при подаче.

> Написано для: тот, кто подаёт приложение в Google Play Console (не разработка кода).

## Что собирается

- **Данные:** координаты (широта/долгота), точность в метрах, время фикса. Ничего
  больше — ни адресов, ни содержимого экрана, ни истории посещений.
- **Где на устройстве:** фиксы складываются в зашифрованную очередь
  (`android/location/SecureLocationQueue`, Tink + Android Keystore) и уходят на
  сервер пачками.
- **Частота:** периодически (сейчас раз в ~15 мин, WorkManager) и в фоне, даже когда
  приложение закрыто.
- **Передача:** только по TLS с привязкой сертификата (`network_security_config`).
- **Кто видит:** только родитель этой семьи, через своё приложение MaxCare.
- **Хранение на сервере:** таблица `device_locations`; родителю отдаётся последняя
  точка и трек за сутки. (Срок хранения задаётся политикой сервера — согласовать.)

## Зачем нужен фон (обоснование для ревью Play)

MaxCare — родительский контроль для детей до 16 лет. Основная заявленная функция —
родитель видит, где находится ребёнок, и его перемещения за день. Это невозможно без
сбора местоположения, когда приложение ребёнка не на переднем плане (телефон в кармане,
экран выключен). Доступ в фоне используется **только** для этой функции и раскрывается
ребёнку/родителю при настройке (постоянное уведомление + видимая иконка; скрытого
режима нет — политика Google Play о мониторинге соблюдена).

## Заметное раскрытие в приложении (как есть в сборке)

Показывается на шаге `LOCATION` мастера настройки **до** системного запроса
разрешения; подтверждающее действие — кнопка «Разрешить геолокацию». Строка
`location_body` (`setup/src/main/res/.../strings.xml`):

- **en:** MaxCare Kids sends this phone's location to you — periodically and in the
  background, even when the app is closed — so you can see where your child is. Tap
  "Allow location", then choose "Allow all the time".
- **ru:** MaxCare Kids отправляет вам местоположение этого телефона — периодически и в
  фоне, даже когда приложение закрыто, — чтобы вы видели, где ребёнок. Нажмите
  «Разрешить геолокацию», затем выберите «Разрешить всегда».
- **uz:** MaxCare Kids bu telefon joylashuvini sizga yuboradi — vaqti-vaqti bilan va
  fonda, ilova yopiq bo'lsa ham, — shunda siz bola qayerdaligini ko'rasiz.
- **uz-Cyrl:** MaxCare Kids бу телефон жойлашувини сизга юборади — вақти-вақти билан ва
  фонда, илова ёпиқ бўлса ҳам, — шунда сиз бола қаердалигини кўрасиз.

Запрос — двухступенчатый (сначала доступ к местоположению обычным диалогом, затем
«Разрешить всегда» через настройки на Android 10+), как требует платформа.

## Ответы формы Data Safety

| Поле | Ответ |
| --- | --- |
| Собирается ли местоположение (approximate/precise) | Да, precise и approximate |
| Передаётся ли третьим лицам | Нет |
| Цель | App functionality; Child safety / parental control |
| Данные обязательны или опциональны | Обязательны для функции геолокации |
| Шифруется ли при передаче | Да (TLS + pinning) |
| Можно ли запросить удаление | Да — при отвязке устройства/удалении семьи |
| Эфемерные (не покидают устройство) | Нет — уходят на сервер |

## Пункт для политики конфиденциальности

**en:** MaxCare collects the child device's location (coordinates, accuracy and time),
including in the background, so the linked parent can see the child's current location
and daily route. Location is sent only to MaxCare's server over an encrypted connection
and is visible only to the child's parent. It is deleted when the device is unlinked.
MaxCare never collects screen contents, messages, or browsing history as location data.

**ru:** MaxCare собирает местоположение телефона ребёнка (координаты, точность и время),
в том числе в фоне, чтобы привязанный родитель видел текущее положение ребёнка и его
маршрут за день. Местоположение передаётся только на сервер MaxCare по шифрованному
каналу и доступно только родителю ребёнка. Удаляется при отвязке устройства. MaxCare не
собирает как геоданные содержимое экрана, переписку или историю посещений.
