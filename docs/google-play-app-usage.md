# Google Play: время в приложениях (`PACKAGE_USAGE_STATS`)

Пакет для публикации MaxCare Kids (`uz.maxcare.kids`): что собирается, заметное раскрытие,
ответы формы Data Safety и пункт для политики конфиденциальности. Заполняется в Play Console
при подаче — вместе с [декларацией геолокации](google-play-location.md).

> Написано для: тот, кто подаёт приложение в Google Play Console (не разработка кода).

## Что собирается

- **Данные:** для каждого календарного дня — название приложения, его пакет и сколько
  миллисекунд оно было на экране. Ничего больше: что ребёнок смотрел, писал или искал внутри
  приложения, не собирается.
- **Какие приложения:** только со значком на рабочем столе, без лаунчера и самого MaxCare Kids;
  меньше минуты за день не отправляется.
- **Источник:** системная история использования (`UsageStatsManager.queryEvents`). Своей копии
  на телефоне MaxCare не хранит — каждый раз пересчитывает последние 3 дня.
- **Частота:** раз в ~15 минут (WorkManager), в фоне.
- **Передача:** только по TLS с привязкой сертификата.
- **Кто видит:** только родитель этой семьи, в приложении MaxCare («Отчёты» → ребёнок →
  «Время в приложениях»).
- **Хранение на сервере:** таблица `app_usage` (день, приложение, минуты). Срок хранения —
  согласовать вместе со сроком для `device_locations`.

## Разрешения и видимость пакетов

- `android.permission.PACKAGE_USAGE_STATS` — особый доступ («Доступ к истории использования»).
  Системного диалога нет: шаг мастера открывает экран настроек, родитель включает доступ сам.
  Насколько известно, отдельной формы-декларации в Play Console для него нет (в отличие от
  службы доступности и фоновой геолокации). **Перед подачей проверить в Play Console** —
  подтвердить это по документации не удалось.
- `QUERY_ALL_PACKAGES` **не используется.** Названия приложений берутся через `<queries>` с
  интентами `MAIN/LAUNCHER` и `MAIN/HOME` (`android/reports/src/main/AndroidManifest.xml`).

## Заметное раскрытие в приложении (как есть в сборке)

1. Общий экран раскрытия (`disclosure_body`) — пункт про время в приложениях добавлен в список
   «Что приложение делает».
2. Отдельный шаг мастера `USAGE_ACCESS` — **до** перехода в настройки; подтверждающее действие —
   кнопка «Открыть доступ». Строка `usage_body` (`setup/src/main/res/.../strings.xml`):

- **en:** MaxCare Kids sends you how long each app was on this phone’s screen each day — every
  15 minutes, in the background. Only the app name and minutes are sent: not what your child
  watched, wrote or searched in it. Tap “Open access”, find MaxCare Kids in the list and turn on
  usage access.
- **ru:** MaxCare Kids отправляет вам, сколько времени каждое приложение было на экране этого
  телефона за день, — раз в 15 минут, в фоне. Передаются только название приложения и минуты:
  что ребёнок смотрел, писал или искал внутри — нет. Нажмите «Открыть доступ», найдите MaxCare
  Kids в списке и включите доступ к истории использования.
- **uz / uz-Cyrl:** см. `values-uz` и `values-b+uz+Cyrl` — **нужна вычитка носителем.**

Если доступ отозвать, мастер снова показывает этот шаг (родитель может отключить защиту прямо
с него паролем — как с остальных шагов восстановления).

## Ответы формы Data Safety

| Поле | Ответ |
| --- | --- |
| Тип данных | App activity → App interactions (время в приложениях); Apps on device (названия приложений) |
| Передаётся ли третьим лицам | Нет |
| Цель | App functionality; parental control |
| Обязательны или опциональны | Обязательны для отчёта «Время в приложениях» |
| Шифруется ли при передаче | Да (TLS + pinning) |
| Можно ли запросить удаление | Да — при отвязке устройства/удалении семьи |
| Эфемерные (не покидают устройство) | Нет — уходят на сервер |

## Пункт для политики конфиденциальности

**en:** MaxCare collects, from the child's device, how long each app was on screen each day
(app name and minutes), so the linked parent can see the child's app usage. MaxCare does not
collect what was viewed, typed or searched inside apps. The data is sent only to MaxCare's server
over an encrypted connection, is visible only to the child's parent and is deleted when the
device is unlinked.

**ru:** MaxCare собирает с телефона ребёнка, сколько времени каждое приложение было на экране
за день (название приложения и минуты), чтобы привязанный родитель видел, чем ребёнок пользуется.
MaxCare не собирает, что ребёнок смотрел, вводил или искал внутри приложений. Данные передаются
только на сервер MaxCare по шифрованному каналу, доступны только родителю ребёнка и удаляются
при отвязке устройства.
