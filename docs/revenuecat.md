# Подписка MaxCare: Google Play + RevenueCat

Подписка — на семью: купить может любой родитель, действует для всех. Цены задаются только
в Play Console, в коде их нет. Что оплачено, решает сервер: после покупки и по уведомлениям
он сам спрашивает RevenueCat (`backend/.../billing/`).

| Статус | Когда | Что работает |
| --- | --- | --- |
| `trial` | 14 дней с регистрации | всё |
| `active` | оплачено | всё |
| `grace` | 3 дня после конца пробного периода или оплаты | всё, вверху приложения — предупреждение |
| `expired` | после отсрочки | в приложении родителя открыты только «Настройки»; остановка защиты на телефоне ребёнка — этап 2 |

Пока ключей нет, оплата выключена: у всех пробный период, на экране «Подписка» — «Оплата в этой
версии приложения недоступна».

## 1. Play Console

1. Приложение `uz.maxcare.parent` загружено хотя бы во внутреннее тестирование: без этого
   Google Play не продаёт ничего, даже тестерам.
2. Монетизация → Подписки → создать две подписки:
   - `maxcare_monthly`, базовый план `monthly`, продление раз в месяц;
   - `maxcare_yearly`, базовый план `yearly`, продление раз в год.
3. Цены — в каждом базовом плане. Проверить, что в списке стран есть Узбекистан.
4. Настройки → Тестирование лицензий: добавить свой Google-аккаунт — покупки будут тестовыми,
   без списания.

## 2. RevenueCat

1. Создать проект MaxCare, добавить приложение Google Play с пакетом `uz.maxcare.parent`.
2. Подключить сервисный аккаунт Google по инструкции RevenueCat. Файл ключа загрузить
   только в RevenueCat: не в чат, не в репозиторий, не на сервер MaxCare.
3. Product catalog → Products: импортировать `maxcare_monthly` и `maxcare_yearly`.
4. Entitlements → создать `pro` и прикрепить к нему оба продукта.
5. Offerings → `default` (текущее): пакеты **Monthly** (`$rc_monthly`) → `maxcare_monthly`,
   **Annual** (`$rc_annual`) → `maxcare_yearly`.
6. API keys:
   - публичный ключ приложения Android (`goog_…`) — для сборки приложения, не секрет;
   - секретный ключ REST API v1 (`sk_…`) — только в `.env` на сервере.
7. Integrations → Webhooks: URL `https://api.maxcare.dexx.uz/v1/billing/revenuecat`,
   Authorization header — то же значение, что `MAXCARE_REVENUECAT_WEBHOOK_AUTH` на сервере.

## 3. Сервер

В `/opt/maxcare/deploy/.env` (заполняет владелец, значения в чат не присылать):

```
MAXCARE_REVENUECAT_API_KEY=sk_…
MAXCARE_REVENUECAT_WEBHOOK_AUTH=Bearer <openssl rand -hex 32>
```

Затем `docker compose up -d server`. Проверка без значений: кнопка «Send test event» в
настройках вебхука RevenueCat должна получить ответ `200`.

## 4. Сборка приложения родителя

```
flutter build apk --dart-define=MAXCARE_REVENUECAT_KEY=goog_… …
```

## Проверка

- Тестер покупает месяц → экран «Подписка» показывает «Оплачено до …», в RevenueCat —
  покупатель с ID семьи (`familyId` из `GET /v1/account`).
- «Восстановить покупки» на другом телефоне того же родителя находит подписку.
- Отмена в Google Play → после окончания периода статус `grace`, через 3 дня `expired`.
  У тестовых покупок месяц длится 5 минут.
