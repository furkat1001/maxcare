# MaxCare — API сервера (спринт 1)

Базовый адрес в разработке: `http://localhost:8080`. Все тела — JSON. Ошибки возвращаются как
`{"error": "<код>"}`; текст для пользователя приложения подбирают сами по коду.

| Код ошибки | HTTP | Когда |
| --- | --- | --- |
| `invalid_request` | 400 | Неверный JSON или поля |
| `email_taken` | 409 | E-mail уже зарегистрирован |
| `invalid_credentials` | 401 | Неверный e-mail или пароль (что именно — не уточняется) |
| `invalid_code` | 400 | Код привязки неверный, истёк или уже использован |
| `not_found` | 404 | Устройства нет или оно чужое (не различаются) |
| `unauthorized` | 401 | Нет или истёк токен сессии родителя |
| `rate_limited` | 429 | Превышен лимит запросов |

## Родитель

### `POST /v1/parents` — регистрация
```json
{"email": "parent@example.test", "password": "минимум 8 символов"}
```
→ `201 {"parentId": "<uuid>"}`. Лимит: 5 в час с одного адреса.

### `POST /v1/sessions` — вход
Тело то же. → `201 {"token": "<токен сессии>"}`, действует 30 дней.
Дальше передаётся в заголовке `Authorization: Bearer <токен>`.
Лимит: 10 попыток за 15 минут на пару «адрес + e-mail».

## Привязка телефона ребёнка

### `POST /v1/pairing-codes` — код привязки (родитель)
```json
{"childName": "необязательно, до 64 символов"}
```
→ `201 {"code": "12345678", "expiresAt": "2026-10-09T10:10:00Z"}`. Код одноразовый, живёт 10 минут.
Лимит: 20 в час на родителя.

### `POST /v1/devices/pair` — привязка (телефон ребёнка, без токена)
```json
{"code": "12345678", "deviceName": "до 64 символов", "platform": "android"}
```
→ `201`:
```json
{"deviceId": "<uuid>", "deviceToken": "<токен устройства>", "recoverySecret": "<base64, 32 байта>"}
```
`deviceToken` и `recoverySecret` выдаются **один раз**: телефон сохраняет их в зашифрованном
хранилище. На сервере токен хранится как SHA-256, секрет — зашифрованным (AES-256-GCM).
Лимит: 10 попыток за 10 минут с одного адреса.

## Код восстановления

### `POST /v1/devices/{deviceId}/recovery-code` (родитель)
→ `200 {"code": "87654321", "validUntil": "2026-10-09T10:10:00Z"}`.
Лимит: 10 в час на родителя.

Если родитель забыл пароль, он получает код здесь и вводит его на телефоне ребёнка.
Телефон проверяет код **без сети** тем же алгоритмом:

- TOTP по RFC 6238 с HMAC-SHA256, 8 цифр;
- ключ — `recoverySecret` из ответа на привязку (32 байта после base64);
- счётчик — `floor(unix_time / 300)` (интервал 5 минут);
- телефон принимает код текущего и предыдущего интервала, то есть код действует 5–10 минут;
- каждый счётчик принимается не больше одного раза (телефон запоминает последний использованный).

Эталонные значения для проверки реализации — RFC 6238, приложение B (SHA-256, 8 цифр);
тест сервера: `backend/src/test/kotlin/.../RecoveryCodesTest.kt`.

## Запуск локально

```bash
cd backend
docker compose up -d          # PostgreSQL и Redis
./gradlew run                 # сервер на :8080 с локальным ключом шифрования
./scripts/dev-pairing-code.sh # регистрирует тестового родителя и выдаёт код привязки
```

В рабочем окружении обязательны переменные `MAXCARE_SECRET_KEY` (base64 от 32 случайных байт),
`MAXCARE_DB_URL`, `MAXCARE_DB_USER`, `MAXCARE_DB_PASSWORD`, `MAXCARE_REDIS_URL`.
