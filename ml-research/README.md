# ml-research — модели фильтра контента

Обучение, оценка и экспорт on-device моделей в `.tflite` для модуля `android/ml`.
Сейчас — классификатор наготы (safe / nsfw). Насилие — отдельной моделью позже,
тем же пайплайном.

## Приватность — обязательно

- **Никогда** не использовать изображения несовершеннолетних — ни для обучения,
  ни для оценки, ни для отладки. Только публичные/синтетические изображения взрослых.
- Датасеты и веса **не коммитятся** (см. `.gitignore`). В репозиторий попадает только код.
- У каждого датасета и предобученной модели проверять лицензию перед использованием.

## Зависимости

TensorFlow пока не поддерживает Python 3.14 — нужен отдельный venv на 3.11/3.12:

```bash
python3.12 -m venv .venv
. .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Датасет

Папки по классам (имена ровно `safe` и `nsfw` — порядок задаёт индексы):

```
data/
  train/
    safe/   *.jpg
    nsfw/   *.jpg
  val/
    safe/   *.jpg
    nsfw/   *.jpg
```

Источники — публичные NSFW-датасеты взрослого контента (их добываете и проверяете
по лицензии сами). Баланс классов и разнообразие (селфи, иллюстрации, скриншоты)
важнее объёма.

## Пайплайн

```bash
# 0. Очистка: найти (и удалить) битые картинки, на которых спотыкается обучение
python clean_data.py --data-dir data            # только показать
python clean_data.py --data-dir data --delete   # удалить

# 1. Обучение (перенос обучения на MobileNetV2)
python train.py --data-dir data --epochs 10 --out models/nsfw.keras

# 2. Оценка: пропуски и ложные срабатывания, перебор порогов
python evaluate.py --data-dir data --model models/nsfw.keras

# 3. Экспорт в .tflite (с проверкой совместимости с Android)
python export.py --model models/nsfw.keras --out models/nsfw_model.tflite --float16
```

## Контракт с Android (`config.py`)

Экспортируемая модель обязана совпадать с
`android/ml/.../LiteRtImageClassifier.kt`:

| Параметр | Значение |
| --- | --- |
| Вход | `(1, 224, 224, 3)`, float, **[0, 1]**, порядок **RGB** |
| Выход | `(1, 2)`, softmax |
| Индекс nsfw | `1` (поэтому `CLASS_NAMES = ["safe", "nsfw"]`) |
| Порог | `0.75` (тот же в Android) |

Нормализация в `[-1, 1]` для MobileNetV2 вшита в модель первым слоем, поэтому
Android подаёт просто `[0, 1]` — ничего пересчитывать на телефоне не нужно.
`export.py` проверяет формы входа/выхода и падает, если они разошлись.

## Поставка модели

Готовый `nsfw_model.tflite`:
- либо в `android/ml/src/main/assets/` (вшить в сборку);
- либо раздавать с сервера (обновление без релиза — см. `docs/sprint-3-4-plan.md`, PR 4/7),
  с версией и контрольной суммой.

Файл в репозиторий не коммитим.

## Метрики (критерий спринта 4)

`evaluate.py` печатает пропуски (nsfw принят за safe), FP на 100 безопасных картинок
и точность для набора порогов. Целевые значения и замер инференса/батареи на телефоне —
в `docs/roadmap.md` и `docs/device-tests.md`.
